# Network & Infrastructure Topology

This document defines the SundaeStackarr homelab topology. It specifies:

* Machine inventory
* Network architecture
* Container-based VPN configuration
* DNS and Pi-hole setup
* DDNS configuration
* SSH access rules
* Drive layout
* SMB share definitions

For arr-stack container details, Docker Compose layout, the utility pipeline, HA integrations, and JukeBot, see other docs in this vault.

Credentials are excluded. See `Reference\Credentials\network-credentials.md` where noted.

Networking and VPN architecture conformance is verified via the live stack status tracker.
