# Lorex N844A8 NVR Operations and Camera Stack Configuration

The camera stack consists of the **Lorex N844A8 NVR** (Dahua OEM), which manages all cameras and 24/7 recording. Detection, event processing, and zoning are handled by on-device decoding on connected tablets; stream output is controlled via RPC2 writes to the NVR.
